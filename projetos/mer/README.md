# Modelo Entidade-Relacionamento (MER)

Projeto de modelagem de dados desenvolvido no [dbdiagram.io](https://dbdiagram.io).

## Arquivos

| Arquivo | Descrição |
|---------|-----------|
| `modelo.dbml` | Definição do diagrama em DBML |
| `diagrama.png` | Exportação visual do diagrama (opcional) |

## Como editar

1. Acesse o projeto no dbdiagram.io
2. Faça as alterações necessárias
3. Exporte o DBML e substitua `modelo.dbml` nesta pasta
4. Commit e push das alterações
